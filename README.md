## Repository layout

```
Allfiles/LabFiles/lab file/   Sample files uploaded in Lab 1 and used in later labs
Instructions/Labs/            Lab instructions (Markdown) and screenshots (Media/)
Instructions/Teaching/        Teaching editions of each lab
Instructions/Trainer/         Trainer Guide
index.md, _config.yml         GitHub Pages site
```

## Publishing the site

In the repository, go to **Settings > Pages**, set **Source** to **Deploy from a branch**, pick **main** and **/ (root)**, and save. The site appears at `https://<owner>.github.io/<repository>/` after a minute or two.

## Notes

- Copilot Cowork is AI-powered: results vary between runs and won't match the screenshots word for word.
- Personal details (user IDs and email addresses) are blurred in all screenshots.
- Lab credentials are provided by your lab environment and are never stored in this repository.
